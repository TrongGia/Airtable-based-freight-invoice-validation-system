## Automated Freight Invoice Validation System

Airtable-based automation project designed to streamline freight invoice validation processes.

The system uses relational tables and automation workflows to validate freight invoices against predefined rate cards and historical EUR-to-USD exchange rates based on invoice issue dates. It automatically calculates expected freight charges, identifies variances, flags exceptions, and sends alert notifications for invoices requiring investigation.
